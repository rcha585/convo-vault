# Personal AI knowledge system

This directory defines the public contract for Convo Vault's knowledge layer.
It contains no private vault content and no user-specific paths.

- [`VAULT_STRUCTURE_V0.2.md`](VAULT_STRUCTURE_V0.2.md): canonical vault layout and storage choices.
- [`DATA_BOUNDARIES.md`](DATA_BOUNDARIES.md): public/private, privacy, and permitted-use rules.
- [`MIGRATION_PLAN_V0.2.md`](MIGRATION_PLAN_V0.2.md): the read-only baseline and migration map for the current experimental vault.
- [`../../schemas/`](../../schemas/): machine-readable JSON Schemas shared by importers, Obsidian notes, and future compilers.

The documents describe the target contract. They do not authorize deletion, source relocation, model training, or publication of private data.
